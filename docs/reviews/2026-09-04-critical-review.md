Reviewed revision: `main` at `76a0a9c0` (engine v0.13.7, Hermes v0.18.2, 23 carried patches, 19 tier-1 extensions, 69 engine crons).

Tracking: okengine#735 (label `review-2026-09-04`); one child issue per numbered finding below, okengine#659 through okengine#734, titled `[review-2026-09-04 #NN]`.
Method: eight parallel read-only review lanes (docs, write path, corpus algorithms, cron/extension machinery, CLI and conformance, test suite, goal fidelity, deploy and read surfaces). Every HIGH finding was reproduced against a scratch vault or re-read in source by the coordinating reviewer. No repo file was modified. Scratch reproductions (`exp1.py`, `exp3.py`, `exp4.py`, `probe.py`, `probe2.py`, `snapcost.py`, scratch packs `p1`, `bA2`, `bD`, `bE`, `rp`, `tamper3.tar.gz`, suite and coverage logs) were run in a session scratchpad and are summarized inline; each child issue carries its own reproduction.

## Verdict

The machinery is real and unusually serious: pinned-and-verified Hermes build, atomic lock protocol, receipted lanes, per-file 100% coverage floor that demonstrably rejects MRs, three-tier extension discovery that fails on duplicates, compose hygiene that matches the operator's container standard. The project also closed the P0s from its own 2026-08-26 review (monoliths split, immutable image tags, `src/okengine` wheel).

The four headline claims are each partly false in code:

| Claim | Status |
|---|---|
| "Enforced write path guards field loss, ownership, reviews, and invariants shared with no_agent lanes" | Key-presence only; ownership is caller-asserted; the model can approve its own review flags; six no_agent lanes write raw text with no shared invariant library. |
| "The engine ships zero domain knowledge" | CTI actor admission runs on every `create_entity`; a CTI `source_kind` taxonomy overrides pack schemas on ingest; the default chat persona is a CTI analyst; an NVD importer sits untiered in `scripts/cron/`; a private deployment's cron name is baked into `write_server.py`. |
| "`framework validate` is the earliest gate" | Exits 0 on a missing cron script, the flat-write okengine#54 loop, a cross-tier duplicate extension id, and non-conformant seed pages. |
| "Layered tests plus a mutation gate" | Coverage is real. Mutation nightly has been red since at least 2026-08-29 with the whole write path unmeasured; the on-main "changed" job diffs main against itself and passes with zero targets; the public GitHub CI cannot collect current HEAD. |

Net: a strong Karpathy-pattern engine with a security-shaped core. Today it is a CTI platform with generalization aspirations rather than a domain-agnostic engine with a CTI pack.
