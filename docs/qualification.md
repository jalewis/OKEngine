# Release qualification

The source and assembled public snapshot are checked before publication.
Release qualification includes separate Python 3.11 and 3.13 compatibility
executions alongside the authoritative Python 3.12 correctness and coverage
results. Evidence belongs to an exact revision, not to a moving branch badge.

For a published version, read its [release notes](https://github.com/jalewis/OKEngine/releases).
New releases must identify the qualified public commit, the qualification
result and completion time, and retained evidence checksums. Private pipeline
links and source details are retained by the maintainer, not exposed here.
Older releases may lack this summary; missing evidence is not a passing result.

This page is a description of the process, not a live pass/fail badge. A green
pipeline permits review; it does not authorize publication. The owner must
explicitly approve the specific public snapshot, tag, and release actions.
